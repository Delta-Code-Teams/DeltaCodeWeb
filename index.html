Desde que entra el equipo hasta que lo entregás.

El flujo es simple: registrás el equipo, presupuestás, reparás, avisás y entregás. La información queda guardada para consultar después.

01

Registrá el equipo

Guardá los datos del cliente, marca, modelo, IMEI o serie, falla y la información necesaria para identificar el equipo.

02

Armá el presupuesto

Sumá repuestos y mano de obra, revisá el total y prepará el presupuesto para compartirlo con el cliente.

03

Actualizá el estado

Mové el equipo entre los estados del taller a medida que avanza la reparación.

04

Avisale al cliente

Cuando terminás, podés avisarle al cliente por WhatsApp sin tener que escribir todo de nuevo.

05

Entregá y cobrá

Registrá el cobro y dejá asentada la entrega. La información queda disponible en el historial.

06

Cerrá el trabajo

El trabajo queda guardado en el historial del cliente para consultarlo cuando vuelva.

Si Windows muestra este aviso, no te asustes.

Al abrir el instalador, Windows puede mostrar "Windows protegió su PC" y señalar a Delta Code como Editor desconocido. Esto puede aparecer porque el instalador no cuenta con un certificado de firma de código reconocido por Windows.

Si descargaste el instalador desde esta página y querés continuar, abrí "Más información" y revisá la información del archivo antes de elegir cómo seguir.
Si te pasaron un instalador por un grupo, un link acortado u otra página, consultanos primero. Para mayor seguridad, usá siempre el enlace de esta página.
